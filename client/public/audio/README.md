# Game sound effects

Two CSNZ sound effects supplied through the local installation are used by the game:

| Runtime asset | Original archive entry | Use |
| --- | --- | --- |
| `client/src/assets/audio/resource-get.wav` | `/cstrike/sound/shelter/zsh_resouceget.wav` | One acquisition cue on every successful Wood/Iron strike, including a first Iron strike before a reward threshold. |
| `client/src/assets/audio/shelter-siren.wav` | `/dstrike/sound/shelterteam/siren.wav` | Alarm when the Shelter core or a structure takes damage. |

The WAV files are unchanged copies: mono PCM, 8-bit, 22050 Hz. No material-impact layer is added to the acquisition cue. Same-frame hit/reward events do not duplicate playback. Sirens are throttled for the sample duration.

Day and night music uses the two user-supplied MP3 files in `client/public/music/`. Volume and crossfade settings are in `shared/audio.json`. Playback starts after a user gesture. Combat and repair effects are generated by `AudioFeedback`.

Unused extracted effects, original Nexon music, archive indexes, video snippets and extraction experiments remain local under ignored `verification/` paths. They are not required to build or run the project. Historical archive-reading tools are also ignored. The original game installation is not modified.
